🔄 DATA FLOW
===========

LOGIN FLOW:
----------
User fills login form
    ↓
System validates Student/Mentor ID + Email + Password against data.js
    ↓
❌ If invalid → Shows "Data Not Found" error
✅ If valid → Saves to localStorage and redirects to dashboard


SESSION SCHEDULING FLOW:
-----------------------
Mentor clicks "Schedule Session" on student card
    ↓
Opens modal with student selection dropdown
    ↓
Mentor fills: Date, Time, Topic, Duration
    ↓
System calls scheduleSessionForStudent() function
    ↓
Function creates notification in data.js GUIDED_DATA
    ↓
Notification saved to localStorage
    ↓
✅ "Session scheduled!" success message shown


NOTIFICATION DISPLAY FLOW:
--------------------------
Student opens dashboard
    ↓
loadStudentNotifications() function runs
    ↓
Fetches notifications from localStorage
    ↓
Updates bell icon badge counter
    ↓
Student clicks bell icon to view notifications
    ↓
Modal shows all scheduled sessions with:
   - Mentor name and session topic
   - Date and time of session
   - Duration information
   - Timestamp when notification was created
   ↓
Student can delete individual notifications

🔑 KEY FUNCTIONS (data.js)
==========================

validateStudentLogin(email, password, id)
  → Returns student object if valid, null if invalid

validateMentorLogin(email, password, id)
  → Returns mentor object if valid, null if invalid

addStudentNotification(studentId, notification)
  → Adds notification to student
  → Saves to localStorage for persistence

getStudentNotifications(studentId)
  → Returns array of all notifications for student
  → Checks localStorage first

scheduleSessionForStudent(studentId, mentorName, sessionDetails)
  → Creates and sends session notification to student
  → Called from mentor-dashboard.js
